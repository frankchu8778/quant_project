# 跨停牌的前向報酬照實計算，不設 NA

深度回測的前向報酬一律用 `close_adj[出場日] / close_adj[進場日] - 1`，即使進出場之間夾著停牌期間也照算，不因為中間不能交易就把該筆觀測標成缺失。

## Considered Options

**設 NA**：跨停牌的持有期間視為無法衡量，該筆觀測從當日截面剔除。

**照實計算**（採用）：停牌只代表中間沒有交易日，還原股價在復牌後仍然連續，報酬本身是可觀測的。

## Consequences

- **這是為了避免存活者偏誤。** 台股會停牌的多半是減資、重大訊息、財報爭議等出事的情形，而出事通常伴隨負報酬。把這些觀測設成 NA，等於系統性地從樣本裡剔除表現最差的一群股票，因子的 IC 與多空價差會被人為美化，而且美化的幅度無從估計。
- 代價是報酬序列裡會混入跨越多個日曆日的觀測值，這些點的波動度天然偏高，會讓 IC 的日間變異變大、ICIR 略微保守。這個方向的偏誤是安全的（低估因子），與存活者偏誤的方向相反。
- **這個決定一旦反轉，所有歷史回測數字全部失效。** 改口徑前後跑出來的 IC / ICIR / 多空價差不能混著比較，也不能拿舊結論當基準。
- 未來讀到報酬欄裡沒有 NA 時，這是刻意的，不是漏掉的邊界處理。
